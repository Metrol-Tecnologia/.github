# .github

Repositório público com o perfil e os arquivos de comunidade padrão da Metrol Tecnologia.

| Arquivo | Efeito |
|---|---|
| `profile/README.md` | Página pública da organização. |
| `CONTRIBUTING.md` | Convenções de branch, commit, PR e segredos. Vale para todo repo que não tenha o próprio arquivo. |
| `.github/pull_request_template.md` | Template padrão de PR. |
| `.github/ISSUE_TEMPLATE/` | Formulários padrão de issue (bug e melhoria). |

Um repositório que tenha a própria versão de um desses arquivos usa a dele no lugar da padrão.

Este repositório é **público**. Não coloque aqui nomes de repositórios privados, dados de clientes, endereços internos ou segredos. O conteúdo interno fica em `.github-private`.
